01How it works

1

Press a key.

One hotkey starts dictation. It works in every app.

2

Speak.

Talk the way you normally do. Your voice is recorded on your own computer.

3

It listens.

Whisper turns your speech into text, on your computer.

4

It types.

The text is pasted where your cursor is.

The speech recognition is done by whisper.cpp. Nothing leaves your computer.

02Features

Dictation in any app

Press the hotkey anywhere and speak. The text is pasted into the window you are working in.

Audio files

Open a WAV, MP3, OGG, M4A, OPUS, FLAC or MP4 file and get a transcript with time stamps that you can search.

Export

Save a transcript as TXT, SRT, VTT or CSV: plain text for notes, subtitles for video, a table for analysis.

50+ languages

The language is detected by itself, with nothing to set up. You can switch language in the middle of a sentence.

Tidy text

Paragraphs, capital letters and punctuation are cleaned up for you. If you turn it on, a language model on your own computer polishes the text further.

Faster with NVIDIA

An NVIDIA graphics card speeds up transcription (CUDA). Without one, the processor does the work.

Private

Everything is processed on your computer. No account, no telemetry, no cloud.

04Before you install

Install what Linux Whisper needs. Pick the block for your system.

Ubuntu, Pop!_OS, Debian

# Build tools, and the GTK4 and libadwaita libraries
sudo apt install build-essential cmake libgtk-4-dev libadwaita-1-dev

# Sound recording (ALSA)
sudo apt install libasound2-dev

# Pasting the text on Wayland
sudo apt install wtype wl-clipboard

# The hotkey: add yourself to the "input" group, then restart the computer
sudo usermod -aG input $USER

# Rust, if you do not have it yet
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Fedora

sudo dnf install gcc cmake gtk4-devel libadwaita-devel alsa-lib-devel wtype wl-clipboard
sudo usermod -aG input $USER

Arch Linux

sudo pacman -S base-devel cmake gtk4 libadwaita alsa-lib wtype wl-clipboard
sudo usermod -aG input $USER

05Install

A ready-made package

Download the latest .deb package or the tarball from the releases page.

Latest release →

From the source

Download the code and build it:

git clone https://github.com/kwap/linux-whisper.git
cd linux-whisper
cargo build --release

Install it for everyone on the computer:

# The program
sudo cp target/release/linux-whisper /usr/local/bin/

# Its entry in the applications menu, and its icon
APP=com.linuxwhisper.LinuxWhisper
sudo cp data/$APP.desktop /usr/share/applications/
sudo cp data/icons/hicolor/scalable/apps/$APP.svg \
  /usr/share/icons/hicolor/scalable/apps/

# Refresh the icons
sudo gtk-update-icon-cache /usr/share/icons/hicolor/

Or let just do both:

just release
just install

06Security

A security audit covered all six crates of the code and the build pipeline. It found the project clean and safe to distribute.

No unsafe code

There is no unsafe block anywhere in the code. Whisper is called through the safe whisper-rs bindings.

Nothing is sent out

No telemetry, analytics or tracking. The only download is the model, over HTTPS from Hugging Face. Your transcripts never leave your computer.

Checked downloads

A downloaded model is compared with its known SHA-256 hash. A damaged or altered file is rejected.

No command injection

Other programs are started with safe arguments and get their input through a pipe. What you say or type is never put into a shell command.

Not a keylogger

The hotkey listener watches only for the hotkey you set. It does not record, store or send any other key.

Pinned build tools

Every build step on GitHub is pinned to an exact commit and checked. No unpinned code from others.

The audit looked for: back doors, data leaving the computer, stolen credentials, misuse of files, gaining extra rights, unsafe calls into other code, command injection, script injection (XSS), the supply chain of the dependencies, and the build pipeline.
